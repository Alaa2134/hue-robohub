# Branded email refresh
Uses private.email_html_branded in the production Resend queue for manual, automatic and test messages. Existing subjects, body text, recipients, suppression lists, rate limits and delivery logic stay unchanged. Arabic/English direction, subject headline, status-specific labels, trusted BuildX CTA, table-based mobile-friendly layout and two existing hosted logos. Preview uses escaped React text, intentionally non-interactive. Unsubscribe links remain when generated for bulk messages. No historical messages are resent; no provider settings change. Rendering verified using synthetic samples, not delivery to an inbox.
