# BuildX AI Studio Pro

محرر فيديو احترافي في المتصفح لفريق BuildX HUE. ترفع فيديوهات وصور وموسيقى، ترتبها على تايملاين متعدد التراكات، تشوف معاينة، وتصدّر MP4 حقيقي. الرندر بيتعمل بـ FFmpeg على سيرفر الفريق، مش في المتصفح.

- **الواجهة:** `buildxhue.com/ar/studio` (موقع ثابت، بيتبني مع الموقع).
- **السيرفر:** API + worker للرندر + Redis. ده **منفصل عن الموقع**، لأن الاستضافة الثابتة (GitHub Pages) مبتشغلش FFmpeg.

> من غير السيرفر، صفحة `/ar/studio` بتقول بوضوح إن سيرفر الرندر مش متوصّل. مفيش أزرار شكلها شغال وهي مبتعملش حاجة.

## اللي شغّال دلوقتي (المرحلة الأولى: من الرفع لحد MP4)

| الجزء | التفاصيل |
| --- | --- |
| المشاريع | إنشاء من قالب أو مقاس، تغيير الاسم، نسخة (بملفاتها)، مسح، حفظ تلقائي بعد ثانية من آخر تعديل |
| الرفع | ملفات كتير مرة واحدة. استئناف لو النت قطع (TUS). نوع الملف والحجم والمساحة بتتراجع على السيرفر قبل الرفع |
| تجهيز الملفات | ffprobe بيقرا النوع والمدة والمقاس والصوت. بيعمل صورة مصغّرة وموجة صوت، ونسخة 720p للمعاينة لو الأصل تقيل على المتصفح (HEVC، 4K، 10-bit) |
| التايملاين | تراكات فيديو وصوت ونص. سحب بين التراكات، قص من الطرفين، قسم عند المؤشر، نسخ، مسح (وكمان مسح وسحب الباقي)، لزق على الحواف، زووم، كتم/إخفاء/قفل للتراك |
| المعاينة | Canvas بنفس قواعد الرندر (`packages/core/src/compose.ts`): الملء، الحركة (Ken Burns)، الشفافية، الظهور والاختفاء، الانتقالات، النصوص العربي |
| الخصائص | المكان والحجم والدوران والشفافية، السرعة، الصوت، الملء (ملء / كامل / كامل + خلفية ضبابية)، الحركة، الانتقال |
| التراجع | Ctrl+Z / Ctrl+Shift+Z، وكل الاختصارات (Space، S، Del، Ctrl+D، الأسهم، T) |
| التصدير | مقاس المشروع أو 720p / 1080p / 4K، و 24 / 25 / 30 / 60 fps، و H.264 + AAC MP4. قبل البدء بيوضح الطول والوقت المتوقع والرصيد الشهري. فيه طابور وتقدّم حقيقي وإلغاء وإعادة محاولة وتحميل |
| الألوان | لكل لقطة: إضاءة وتباين وتشبّع، ودافي أو بارد. وفيه درجات جاهزة: زاهي، دافي، بارد، سينمائي، أبيض وأسود، باهت. في الرندر بـ `eq` و `colorbalance`، وفي المعاينة بفلاتر الـ canvas |
| قوالب العناوين | نص عادي، صندوق، اسم ووظيفة (lower third بخط مميز في ناحية القراءة)، عنوان كبير بخط تحته، شريط ترجمة. ليها سطر تاني ولون مميز وحركة دخول وخروج (يطلع من تحت أو يدخل من الجنب) بمنحنى ناعم. الحركة نفسها في المعاينة والرندر |
| خفض الموسيقى | الموسيقى بتوطى لوحدها لما يبقى فيه كلام في الفيديو (sidechain compression في FFmpeg) |
| تجميع تلقائي | يرصّ كل الفيديوهات والصور بالتبادل، بأحسن جزء من كل فيديو وحركة خفيفة للصور وتداخل ناعم، والموسيقى تحت. ده **محلي: من غير AI ومن غير تكلفة** |
| الأمان | أدمن ومحرر. روابط ملفات موقّعة ومؤقتة. RLS في Supabase. المفاتيح على السيرفر بس. حدود للمساحة ولدقايق الرندر في الشهر لكل شخص |

## المراحل الجاية

1. **محرر متقدم:** LUT، كيفريمز للخصائص، مكتبة انتقالات وتأثيرات، مشاركة المشروع مع محرر تاني، نسخ قديمة.
2. **موشن جرافيك:** intro و outro جاهزين بلوجو الفريق، وخطوط مرفوعة.
3. **AI (مقفول لحد ما المفتاح يتحط، وكل استدعاء بيظهر تكلفته قبل ما يشتغل):**
   - تعليمات بالكلام ("اعمل ريل 30 ثانية للفعالية بموسيقى حماسية").
   - اختيار اللقطات بـ Gemini، وده بعد تحليل محلي ببلاش أول: كشف المشاهد بـ FFmpeg، والوجوه والحركة بـ OpenCV.
   - تعديلات بالمحادثة على تايملاين قابل للتعديل.
4. **رندر أسرع:** تقسيم الفيديو لأجزاء على أكتر من worker، وGPU (NVENC) لو السيرفر فيه.
5. **Remotion:** مؤجّل. رخصته مجانية للأفراد والمؤسسات اللي فيها 3 موظفين أو أقل؛ لازم نراجعها قبل ما نستخدمها.

## التصميم

```
المتصفح (apps/web)                      السيرفر
─────────────────                       ───────────────────────────────────────────
Dashboard · Editor ── REST/JSON ──►     API (apps/api, Fastify)
  └ Canvas preview                        ├ يتحقق من الجلسة والدور والصلاحية على المشروع
  └ TUS uploads ──────────────────►       ├ تذاكر الرفع + روابط موقّعة
        (لـ Supabase Storage مباشرة،      ├ Postgres (schema studio)
         أو لـ /uploads على السيرفر)      └ BullMQ ─► Redis ─► Worker (apps/worker)
                                                                ├ ingest: ffprobe, thumb, waveform, proxy
                                                                ├ render: EDL → FFmpeg → MP4 → تحقق → تخزين
                                                                └ cleanup: مسح ملفات المشاريع المشالة
```

| المجلد | فيه إيه |
| --- | --- |
| `packages/core` | نموذج قرارات المونتاج (EDL)، عمليات التايملاين، قواعد الكادر للمعاينة، وتحويل التايملاين لأمر FFmpeg واحد. كله pure ومتختبر |
| `packages/server` | الإعدادات، Postgres، التخزين (supabase أو local)، الطوابير |
| `apps/api` | REST API |
| `apps/worker` | تشغيل FFmpeg و ffprobe |
| `apps/web` | الواجهة (React + Vite + Tailwind) |
| `db/supabase.sql` | RLS والـ bucket الخاص. اتطبّق على المشروع كـ `supabase/migrations/20261031900000_studio.sql` |

### قاعدة البيانات (`packages/server/src/schema.sql`)

- **`studio.members`:** الإيميل، `user_id`، الدور (admin/editor)، مفعّل ولا لأ، ودقايق الرندر الشهرية.
- **`studio.projects`:** الاسم، المالك، التايملاين (JSON حسب `edl.ts`)، و`timeline_version`. أي حفظ من نسخة أقدم بيترفض بـ 409، فتابين مفتوحين مش هيمسحوا شغل بعض.
- **`studio.project_members`:** مين شغال على المشروع ودوره (owner/editor/viewer).
- **`studio.assets`:** الملف، الحالة (uploading ← processing ← ready/failed)، وبيانات ffprobe (مدة، مقاس، fps، صوت، codec)، والصورة المصغّرة والنسخة المخففة وموجة الصوت.
- **`studio.renders`:** الحالة، التقدّم، طلب الإلغاء، الإعدادات، **نسخة من التايملاين وقت التصدير** (علشان إعادة المحاولة ترندر نفس المونتاج بالظبط)، الملف الناتج وحجمه، رقم المحاولة.
- **`studio.usage`:** ثواني الرندر وتكلفة الـ AI، علشان الحدود الشهرية.
- **مفيش حذف صفوف:** اللي بيتشال بياخد علامة `removed_at`، والملفات بتتمسح من التخزين في الخلفية.

### خط الرندر

`planRender()` في `packages/core/src/render-plan.ts` بيحوّل التايملاين لأمر FFmpeg واحد:

1. **الخلفية:** لون بطول المخرج بالظبط وبالـ fps المطلوب.
2. **كل كليب مرئي، من أسفل تراك لأعلى:**
   - `-ss/-t` من المصدر، والسرعة.
   - الملء: cover أو contain أو blur.
   - Ken Burns بـ `zoompan`.
   - الحجم والمكان والدوران والشفافية.
   - الظهور والاختفاء.
   - الانتقالات: تداخل ناعم (الكليب اللي قبله بيكمّل تحته)، أو غمقة للأسود، أو دخول من الجنب.
   - بعدها `overlay` في وقته.
3. **النصوص:** بتترسم PNG بنفس الخطوط ونفس دالة الرسم بتاعة المعاينة (`titles.ts`). العربي متشكّل صح.
4. **الصوت:** كل كليب فيه صوت بيتقص، ويتظبط وقته وسرعته ومستواه، ويدخل ويخرج بالتدريج. بعدها `amix` و `alimiter`. ولو مفيش صوت خالص، بيتحط صمت.
5. **الإخراج:** `libx264` و `yuv420p` و AAC 48kHz و `+faststart`. التقدّم بيتحسب من `-progress` الحقيقي.
6. **قبل ما يتعلّم «جاهز»:** ffprobe بيتأكد إن الملف H.264 وطوله صح. وبعدها بس بيترفع للتخزين.

## التشغيل محليًا

```bash
cd studio
npm ci
node scripts/services.mjs start      # Postgres + Redis محليين من غير Docker
cp .env.example .env                  # STUDIO_AUTH=local, STUDIO_STORAGE=local, STUDIO_LOCAL_USERS=…
npm run dev:api & npm run dev:worker & VITE_STUDIO_API_URL=http://localhost:8787 npm run dev:web
```

## الاختبارات

```bash
npm test          # وحدات + مسار السيرفر كامل على Postgres و Redis و FFmpeg حقيقيين
npm run e2e       # المتصفح: رفع 5 فيديوهات و10 صور، مونتاج، معاينة، تصدير MP4 30 ثانية وتحميله وفحصه
```

الـ CI (`.github/workflows/ci.yml`، job `studio`) بيشغّل الاتنين الأولانيين على كل PR.

## النشر

اللي محتاجه: سيرفر Linux فيه Docker. يكفي 2 vCPU و 4GB رام، وكل ما زاد الـ CPU الرندر بيبقى أسرع. ينفع VPS (Hetzner أو DigitalOcean أو Contabo) أو Railway أو Fly.io.

1. **Supabase:** الجداول والـ RLS والـ bucket اتطبّقوا خلاص على المشروع. ومن **Project Settings ← Database** هات connection string بتاع الـ Session pooler.
2. **السيرفر:**
   ```bash
   git clone … && cd hue-robohub/studio
   cp .env.example .env    # املا القيم (الشرح جوه الملف)
   docker compose up -d --build
   ```
   - حط HTTPS قدامه، بـ Caddy مثلًا: `studio-api.buildxhue.com { reverse_proxy localhost:8787 }`.
   - **التخزين:** `STUDIO_STORAGE=local` (على قرص السيرفر) أرخص، ومن غير حد 50 ميجا اللي في خطة Supabase المجانية. ولو اخترت `supabase`، Pro هو اللي بيسمح بفيديوهات كبيرة.
3. **الموقع:** في GitHub ← **Settings ← Secrets and variables ← Actions ← Variables**، اعمل `STUDIO_API_URL` = `https://studio-api.buildxhue.com`. أول ما الموقع يتبني تاني، `/ar/studio` هيتصل بالسيرفر.
4. **الدخول:** حط إيميلك في `STUDIO_ADMIN_EMAILS`، وادخل بحسابك على الموقع. بعد كده ضيف المحررين من صفحة «الفريق».

## التكلفة

- **الرندر:** CPU على السيرفر بتاعكم، ومفيش تكلفة لكل فيديو. ريل 30 ثانية 1080p بياخد حوالي دقيقة على 2 vCPU.
- **الـ AI:** مقفول من غير `GEMINI_API_KEY`. ولما يتفتح، كل طلب بيظهر تكلفته المتوقعة الأول، وفيه حد شهري (`AI_MONTHLY_USD`).
