# BuildX HUE — website & BuildX App

Published files for **https://buildxhue.com** (Student Innovation & Robotics Community, Horus University – Egypt).

- Website (English at the root, Arabic under `/ar/`)
- BuildX App at `/app/`: barcode attendance, course content and quizzes for students and the training team. Install it on iPhone or Android from the browser (Add to Home Screen / Install app).

The `gh-pages` branch holds the built site; its `CNAME` file binds it to `buildxhue.com`. The source code lives in a private repository.
