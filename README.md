# HUE RoboHub — website & RoboHub App

Published files for **https://alaa2134.github.io/hue-robohub/**

- Website (English at the root, Arabic under `/ar/`)
- RoboHub App at `/app/`: barcode attendance, course content and quizzes for students and the training team. Install it on iPhone or Android from the browser (Add to Home Screen / Install app).

The `gh-pages` branch holds the built site. The source code lives in a private repository.
